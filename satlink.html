Plain limits to know first

  • The full NPCT library uses 1.2 MB of memory on Linux boards and PCs. Small Arm chips with 64 KB of memory use our lighter encoder, tested in chip emulators so far.
  • Binary packets like MAVLink and AIS shrink about 2 times. Text logs shrink 4 to 8 times, and one single 94-byte buoy reading drops from 2 credits to 1.
  • NPCT checks for broken data and signs alarms, but it does not encrypt message text.
  • We ran these drone and satellite link tests in software simulators and on a Raspberry Pi 4, not on live satellites or flying aircraft yet.
  • A qualified person must check all test results before field use.
